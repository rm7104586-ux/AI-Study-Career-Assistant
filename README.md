# AI Study & Career Assistant

An AI-powered full-stack web application designed to help students with studying, learning, career preparation, and resume improvement.

## Features

- 🔐 User Registration & Login
- 🤖 AI Chat Assistant
- 📚 Notes Analyzer
- 📝 AI Quiz Generator
- 📄 Resume Analyzer
- 👤 User Profile
- 📊 Recent Activity Tracking
- 🔑 JWT Authentication
- 🗄️ PostgreSQL Database
- 🌐 Deployed Full-Stack Application

## AI Features

### AI Chat
Ask questions and receive intelligent responses using Google Gemini.

### Notes Analyzer
Upload:
- PDF
- DOCX
- TXT
- PPTX

The system analyzes the uploaded notes and provides:
- Summary
- Key Points
- Important Concepts
- Revision Topics
- Exam Questions

### AI Quiz Generator
Generate quizzes based on a chosen topic, question count, and difficulty level.

### Resume Analyzer
Upload a PDF resume and receive:
- Resume Score
- Strengths
- Weaknesses
- Skills Feedback
- Project Feedback
- ATS Recommendations
- Career Recommendations
- Action Plan
